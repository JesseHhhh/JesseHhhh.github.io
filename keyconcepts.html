6 SEO Key Concepts

1. Keywords

Specific words that users type into a search engine.

2. Crawling

Whenever a search engine bot browses through the web and locates websites.

3. Indexing

A search engine that indexes pages happens after crawling a page and stores them that can be searched later on.

4. Ranking

The ordering of the search result based of the SEO.

5. Backlinks

Links from external websites that lead back to the internal website.

6. Metadata

Information in a web page's HTML that describes the page.
